# **App Name**: Data Harbor

## Core Features:

- Profile Display: Showcase a professional photo with a brief personal introduction.
- Resume Download: Provide a button to easily download the resume in PDF format.
- Website Visit Counter: Track and display the number of visits to the portfolio.
- Project Showcase: Display data analysis projects with screenshots, descriptions, and links.
- Skills Section: Highlight data analysis tools and languages with visual representations.
- Contact Form: Implement a contact form for potential employers to reach out.
- Social Media Integration: Connect to various social media platform such as Linkedin or Github profile

## Style Guidelines:

- Background color: Dark Navy (#0a192f) for a professional base.
- Accent color: Cyan (#00e5ff) as circular glow to attract attention and add a modern touch.
- Highlight color: Light Blue (#2196f3) to show actions.
- CV Button color: Magenta (#ff4081) to help users find CV section more intuitively.
- Headline font: 'Space Grotesk' (sans-serif) for headlines and short amounts of body text. Body font: 'Inter' (sans-serif) for longer body text.
- Subtle animations to create a professional aesthetic that can include effects such as fading sections.
